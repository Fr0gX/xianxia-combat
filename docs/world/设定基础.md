# 设定基础

这是一个原创的传统修仙世界，取《凡人修仙传》一类作品中修行漫长、境界森严的气质，不沿用其人物或剧情。当前故事主要发生在人界的天南地区。没有修行资质的人统称无资质者；修士从练气开始。

## 境界

| 境界 | 寿元上限 | 修行的主要变化 |
|---|---:|---|
| 练气 | 80岁 | 感应并吸纳灵气，由散乱运气走向稳定的液态真元。仍是肉体凡胎。 |
| 筑基 | 200岁 | 建立、夯实丹田基台，灵气运作成体系，可以施展神通。 |
| 结丹 | 500岁 | 真元凝成金丹，开始以丹火温养本命法宝；后期神识渐与丹息相合。 |
| 元婴 | 1200岁 | 破丹结婴，元婴可自行吐纳；高阶修士能以婴身、神识和天地灵气施展更强的手段。 |
| 化神 | 3000岁 | 元神凝聚，可借元婴沟通天地，形成领域。人界的化神中后期之路受天地条件限制。 |

每一大境界有前期、中期、后期；后期修满称圆满，之后方能尝试冲击下一大境界。小境界之间也有瓶颈，前、中、后期的修炼成本并不均匀，越往后越难。失败会耗去积累与时间；寿元是绝对年龄上限，不因突破而重新计数。资质、宗门条件、资源和当地灵气质量共同影响修炼速度与突破机会，但没有“保送”或“禁止化神”的资格规则。

境界不是单纯的数值标签。练气修士在凡人眼中已可称高人，面对同境修士却可能十分脆弱；结丹已能凭神通、法宝与灵兽形成完整战斗体系；元婴和结丹之间有显著鸿沟。具体到每个小境界的身体变化、攻防方式和战斗表现，以原设计稿 `level.md` 为准。

## 资质与人生

| 资质 | 无宗门增益时常见的人生终点 |
|---|---|
| 较差 | 几乎都停在练气。 |
| 普通 | 多数止于筑基，结丹极罕见。 |
| 良好 | 多数止于筑基，有一部分结丹。 |
| 天才 | 多数止于结丹，元婴极罕见。 |
| 顶级 | 多数止于结丹，有一部分元婴。 |
| 超凡 | 多数可至元婴，极少数化神。 |

这是大量人生的概率分布，不规定单个人的身份、性情、苦乐或地位。超凡资质极稀少，平均每纪约出现一至两人；化神仍需资质、环境、资源、突破运气与漫长寿元共同支持。

## 宗门、家族与散修

修士由整个世界产生，再由各组织吸纳；宗门和家族不能自行创造新人。未入门墙的人是散修。家族与宗门同属修仙组织，只是组织形式、称呼和生活不同。宗门有低幅、普遍的修炼增益，也有按小境界分别分配的稀缺资源；资源能显著改善修炼与突破，却不是晋升资格。大宗更愿意从初入道时培养弟子，小宗与家族更常吸纳已经显出修为的散修。

宗门话事权像逐张比牌：先看最高小境界的人数，同数再看该境界最强者的战力，然后才往下比较。顶级、大型、中型、小型、微型五档由排位断层形成，并非按固定元婴人数封号。宗门等级影响下一轮招生与修炼条件，不倒过来改写已发生的人生。

传统修仙要素——国家、山海、宗门结盟、秘境古迹、功法神通、法宝灵兽与天材地宝——都可在这个底盘上展开；目前并没有把每一处山河、每一件宝物都定死。
